# What's new in 0.9

## A page like this one for every release worth it

The announcement card at the top of your start page feed now opens a What's new page for the release, with short clips of what changed. Smaller releases still announce themselves and link to their section of the changelog.

- **What's new:** one page per release worth a closer look, listed under [All releases](/whats-new).
- **Changelog:** every release, small ones included, is on the [changelog](/changelog) page, which also has feeds to follow.
- **Your own news:** on a self-hosted server you can add announcements of your own. See [Contributing](https://github.com/adrianmross/pursuit/blob/main/CONTRIBUTING.md#announcements-and-whats-new).

<Clip src="/docs/whats-new/0-9/whats-new" width={720} height={450} caption="The announcement card opens the What's new page for the release." />

## Replay the guided tour

The short walk through the dashboard used to be offered once, in a demo sandbox. You can now start it again in any account: open **Settings › About** and choose **Replay tour**.

<Clip src="/docs/whats-new/0-9/tour" width={720} height={450} caption="Settings, About, Replay tour: the tour starts again on the start page." />

## Plans and early features: coming soon

Smart search and tailored documents from [0.8](/whats-new/0-8), and the Plus plan that sells them, are parked for now. Settings shows them as **Coming soon**, switched off, under **Experimental** and **Plan**, and the Upgrade button is disabled. Nothing behind them answers while they are parked.

<Callout type="info">
  This applies to the hosted service and to a self-hosted server alike. To try them on your own server, set `PURSUIT_PREMIUM_FEATURES=on`. Stripe stays unconfigured until you do, even with `STRIPE_SECRET_KEY` set.
</Callout>

<Clip src="/docs/whats-new/0-9/coming-soon" width={720} height={450} caption="Settings, Experimental and Plan: smart search, tailored documents and Plus show as coming soon." />

## Also in 0.9

- For development, `devenv up --profile s3` runs a local S3 for documents, and a missing document bucket is now named in the error.
- An unexpected server error is now written to the log instead of being hidden.
- `PURSUIT_FIXED_TIME` freezes the server's clock, for recording demos and screenshots of the example data that come out the same every time. Never set it on a server people use.
