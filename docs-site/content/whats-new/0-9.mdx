# What's new in 0.9

## A page like this one for every release worth it

The announcement card at the top of your start page feed now opens a What's new page for the release, with short clips of what changed. Smaller releases still announce themselves and link to their section of the changelog.

- **What's new:** one page per release worth a closer look, listed under [All releases](/whats-new).
- **Changelog:** every release, small ones included, is on the [changelog](/changelog) page, which also has feeds to follow.
- **Your own news:** on a self-hosted server you can add announcements of your own. See [Contributing](https://github.com/adrianmross/pursuit/blob/main/CONTRIBUTING.md#announcements-and-whats-new).

## Replay the guided tour

The short walk through the dashboard used to be offered once, in a demo sandbox. You can now start it again in any account: open **Settings › About** and choose **Replay tour**.

<Clip src="/docs/whats-new/0-9/tour" width={720} height={450} caption="Settings, About, Replay tour: the tour starts again on the start page." />

## Also in 0.9

- On the hosted service, <Premium /> features and plans show as coming soon until they are switched on. A self-hosted server still includes them.
- For development, `devenv up --profile s3` runs a local S3 for documents, and a missing document bucket is now named in the error.
