# Getting started

```bash
brew install adrianmross/tap/pursuit
pursuit serve
```

Linux and Windows binaries, and the browser extension zip, are on [GitHub Releases](https://github.com/adrianmross/pursuit/releases). To build from source you need Go 1.26 and Node 22: `make build` builds the embedded dashboard and docs, then `bin/pursuit`.

With no database URL the daemon creates `~/.local/share/pursuit/pursuit.db` and listens on `:8787`. The first start logs a bootstrap token once — save it, it is not written to disk.

```bash
export PURSUIT_TOKEN=pst_...
export PURSUIT_SERVER=http://127.0.0.1:8787

pursuit import seed
pursuit list --status to_apply --fields id,company,title,status
```

## Applicant profile

Answers and the résumé file stay outside the repo:

```bash
export PURSUIT_PROFILE=$HOME/.config/pursuit/profile.json
export PURSUIT_RESUME_FILE=$HOME/.config/pursuit/resume.pdf
export PURSUIT_CONTACT_EMAIL=you@example.com
```

`profile.json` is `{"answers": {"email": "...", "work_authorization": "..."}}`. Keys match form questions after lowercasing and turning other characters into underscores (`why_us`, `cover_letter`).

## Postgres, for more than one replica

```bash
export PURSUIT_DATABASE_URL='postgres://pursuit:pursuit@127.0.0.1:5432/pursuit?sslmode=disable'
pursuit serve
```

Use `sslmode=require` for Neon. Queue claims use `SELECT ... FOR UPDATE SKIP LOCKED`; the link sweep takes a Postgres advisory lock so only one replica checks postings. `devenv up --profile postgres` starts Postgres and two replicas on ports 8787 and 8788. `docker compose up --build` runs the same stack in Docker; `docker-compose.yml` is generated from `devenv.nix` (`devenv tasks run dev:compose`).

## The dashboard

`pursuit serve` embeds a small web dashboard at the same address as the API. Open it and paste a token once — the browser keeps it in `localStorage` and sends it as `Authorization: Bearer`. A read token can browse; Approve and Reject need `approve`; re-checking a posting needs `write`.

## Browser extension

`extension/` is a Manifest V3 extension that saves the posting you have open and fills Greenhouse, Ashby and Lever application forms. It does not crawl, and it never clicks Submit.

```bash
cd extension
npm install
npm run build
```

Pair it from the popup with the server URL and a token that has `write` and not `approve` (mint one with `pursuit tokens create`).
