# Changelog

<Callout type="warning">
  **pursuit is pre-release (`0.x`).** The CLI, API and docs can change between any two versions.
</Callout>

One version covers the CLI, server, HTTP API, dashboard, docs and browser extension. `pursuit version` and `GET /version` report it, and `/openapi.json` carries it in `info.version`.

Follow releases with the [Atom feed](https://hirepursuit.app/docs/changelog.xml), the [JSON Feed](https://hirepursuit.app/docs/changelog.json) or GitHub's [releases feed](https://github.com/adrianmross/pursuit/releases.atom). Release notes live in [`CHANGELOG.md`](https://github.com/adrianmross/pursuit/blob/main/CHANGELOG.md) and on [GitHub Releases](https://github.com/adrianmross/pursuit/releases), which also carry the binaries and the extension zip.

Each user-visible change carries a [changelogger](https://github.com/adrianmross/changelogger) fragment; Release Please turns merged changes into a release PR. See [CONTRIBUTING.md](https://github.com/adrianmross/pursuit/blob/main/CONTRIBUTING.md#releases).
